DealHound — a real Black Friday deal finder: 34 deals price-checked on 27 Nov 2026 at Amazon, Best Buy, Walmart, Target, Samsung and Disney+, each with an honest verdict (new low, strong price, routine sale or inflated sale) and the evidence behind it. Search and filters by category, store, discount and verdict all work; the same product is compared across stores where it is sold in more than one.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Build the hand-in bundle the same way the grader does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
